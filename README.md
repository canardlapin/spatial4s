# spatial4s

spatial4s is the neutral coordinate kernel shared by image4s, mesh4s, and
reframe4s.

The project is currently at its 0.1 contract-freeze stage. The authoritative
contract is [docs/contract.md](docs/contract.md).

`spatial4s.Frame` means a typed coordinate frame. It is unrelated to the
existing `frame4s` typed dataframe library.
